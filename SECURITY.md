# Security

To report a security problem in the MarketAI Connector, use **Report a vulnerability** on
this repository's [Security tab](https://github.com/sergimes/marketai-connector/security).
Only we can read what you send there. Please do not open a public issue.

Say what you found, and how to reproduce it. We confirm that we received it, keep you
informed until it is fixed, and fix it in the latest release. With automatic updates on, a fix
reaches every bot within a quarter of an hour. Once the fix is out, we list it in the
[release notes](https://github.com/sergimes/marketai-connector/releases).

We fix security problems in the latest release. If you stay on an older version, update
to get the fix.
