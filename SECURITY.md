# Security

To report a security problem in the MarketAI Connector, please use **Report a
vulnerability** on this repository's
[Security tab](https://github.com/sergimes/marketai-connector/security). Only we can read
what you send there. Please do not open a public issue.

Please describe what you found and how to reproduce it. We will confirm that we received
your report, keep you informed until the problem is fixed, and fix it in the latest
release. With automatic updates on, a fix reaches every bot within a quarter of an hour.
Once the fix is released, we list it in the
[release notes](https://github.com/sergimes/marketai-connector/releases).

Security fixes are made in the latest release. If you stay on an older version, please
update to receive the fix.
